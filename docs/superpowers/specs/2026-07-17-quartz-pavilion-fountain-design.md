# 石英亭阁喷泉设计规格

## 目标

生成一座可直接导入 Minecraft Java 版 1.21.11 / WorldEdit 的地标级石英喷泉，并以 Sponge Schematic v3 的 `.schem` 文件交付到项目中。生成过程必须可复现，成品必须能由本项目现有解析器反向读取。

## 已确认方向

- 体量：严格限制在 `35 × 35 × 24` 方块包围盒内。
- 风格：方案 B，新古典亭阁式建筑喷泉。
- 配色：清雅白蓝，以石英与水体为主，海晶灯只作为隐藏照明。
- 布局：四向完全对称，四面均可进入和观赏。
- 交付：保留生成器，同时提交最终 `.schem` 成品。

## 建筑设计

### 台基与主池

建筑以 `17,17` 为平面中心。最底层使用三层八边形台基塑造约 33 格宽的广场轮廓，主池直径约 27 至 29 格。四个正方向各设置 5 格宽入口，入口从结构边界连续通向柱廊和中央喷泉，不得被水体或装饰阻断。

池壁使用石英块、平滑石英台阶和石英楼梯形成多层收边。水面低于最外侧步道，池底封闭且连续，所有水源必须被池壁约束在结构包围盒内。

### 柱廊与屋顶

主池内圈布置 12 根石英柱。每根柱由柱础、竖纹石英柱身和外挑柱头组成，承托连续环形檐口。四个正立面各形成明确的入口开间，并在檐口上方设置三角山花。

屋顶采用低矮阶梯穹顶与四向山花结合的轮廓，中心留出视觉焦点，使中央水柱和顶部冠饰在远景中清晰可见。建筑内部保持开放，不设置门、实体或需要支撑更新的悬空细节。

### 中央喷泉

中央喷泉由底座、下层大水盘、中层小水盘和顶部冠饰组成。顶部使用水源方块形成主水柱，中层设置四向对称的落水路径，水最终落入主池。

水体既是结构内容也是蓝色视觉点缀。水源布局必须在加载后保持稳定，不依赖红石、命令方块、实体或随机刻。海晶灯隐藏在主池底部、中央底座和檐口内侧，从主要视角不直接暴露大面积发光表面。

## 材质范围

主体调色板限定为以下原版方块状态：

- `minecraft:quartz_block`
- `minecraft:smooth_quartz`
- `minecraft:quartz_pillar[axis=y]`
- `minecraft:quartz_stairs` 的必要朝向、半砖位和形状状态
- `minecraft:quartz_slab` 与 `minecraft:smooth_quartz_slab` 的必要类型状态
- `minecraft:chiseled_quartz_block`
- `minecraft:sea_lantern`
- `minecraft:water[level=0]`
- `minecraft:air`

不使用金属、有色玻璃、紫水晶、植物、实体或方块实体，以保持纯净的新古典白蓝风格和跨工具兼容性。

## 生成架构

新增 `scripts/generate-quartz-fountain.mjs`。脚本只使用 Node.js 内置模块，内部职责分为：

1. 三维方块体积与边界安全的放置接口。
2. 圆、八边形、环、线段、楼梯朝向和四向镜像等几何辅助函数。
3. 台基、池体、柱廊、屋顶、中央水景和隐藏照明的独立构建阶段。
4. 方块状态调色板收集、VarInt 编码、NBT 写入与 gzip 压缩。
5. 尺寸、方块统计、对称性和关键通路的生成后校验。

脚本每次运行均覆盖生成 `public/schematics/quartz-pavilion-fountain.schem`，相同源码必须产生语义一致的结构。项目网页功能不做修改，也不把该文件自动加入首页示例列表。

## Schematic 格式

成品使用 Sponge Schematic v3 根结构，采用 gzip 压缩 NBT，数据版本固定为 Minecraft Java 1.21.11 的 `4671`。结构包含：

- `Version = 3`
- `DataVersion = 4671`
- `Width = 35`
- `Height = 24`
- `Length = 35`
- `Offset = [0, 0, 0]`
- `Blocks.Palette`
- `Blocks.Data`
- 空的方块实体、实体与必要元数据集合

方块线性顺序与项目解析器一致：`x + z * width + y * width * length`。调色板索引采用无符号 VarInt 连续编码。

## 错误处理

生成器遇到越界放置、无效方块状态、尺寸不匹配、调色板索引错误或 VarInt 数据长度异常时立即以非零状态退出，不写出部分成品。文件先在目标目录写入临时文件，全部校验成功后再替换最终 `.schem`。

## 验收标准

- 成品尺寸严格为 `35 × 35 × 24`，所有非空气方块均在包围盒内。
- 本项目 `parseNbt` 与 `normalizeSchematic` 能读取生成文件，识别为 Schematic v3 / DataVersion 4671。
- 结构在 X、Z 两个轴向上四向对称；具有四个连续、至少 5 格宽的入口。
- 主池底与池壁连续，水源不位于外边界，水体只出现在池和中央喷泉预定区域。
- 12 根柱的柱础、柱身和柱头完整，四面山花与中央三级水盘存在。
- 调色板只包含本规格列出的方块状态族，不包含方块实体或实体。
- 专用生成测试、项目现有 `npm test` 和 `npm run build` 均成功。
- 生成结束时打印总方块数及各方块状态用量，作为建造材料统计。

## 非目标

- 不修改查看器界面或增加内置示例选择功能。
- 不生成基岩版 `.mcstructure`、旧版 `.schematic` 或 Litematica `.litematic`。
- 不添加红石动画、命令方块、粒子、实体或生物装饰。
- 不额外生成多个尺寸或配色变体。
